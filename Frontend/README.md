
# Frontend (3DVerse AI)

## Setup

1. Install dependencies:
   - `npm install`
2. Configure API URL (optional):
   - Copy `.env.example` to `.env`
   - Set `VITE_API_BASE_URL` if backend is not on `http://localhost:5000`
3. Start dev server:
   - `npm run dev`

## Build

- `npm run build`

## Notes

- This frontend expects the backend service to be running.
- Main connected features: upload, text-to-3D generation, manual builder, AR link/QR, and project gallery.
